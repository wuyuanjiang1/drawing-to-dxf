# 图纸照片/截图测量方法

目标：从尺寸图位图中恢复特征坐标（mm），供 DXF 生成使用。核心思路——**标注数值是权威，像素测量只是把数值挂到特征上**。

## 1. 图源优先级

1. **清晰截图**（矢量图导出、商品页原图）：定拓扑（哪些特征在哪、引线指向谁）
2. **高清照片**（手机拍屏幕）：定数值（大图像素多，量得准）
3. 两者冲突时：标注数值 > 清晰截图 > 照片像素

屏幕照片有摩尔纹：强边线旁常出现 0.5~1.5mm 等距「幽灵线」，水平方向还会出现假长线。判断方法：幽灵线在清晰截图里不存在；真线的长度范围与特征一致。

## 2. 比例尺标定

先找图纸上**已标注**的距离，量像素，得 px/mm：

- 两个正交方向都要标定，互差应 <2%（否则照片畸变，以更可信的方向为准）
- 多个已知尺寸取平均（如 29 高、42 长）
- 示例：某照片 20mm 孔距 = 508px，12mm 孔距 = 305px → 25.40 与 25.42 px/mm ✓

## 3. 特征检测（numpy + Pillow）

```python
import numpy as np
from PIL import Image
b = np.array(Image.open(p).convert("L")) < 115   # 阈值按图调整 (110~140)

def runs(line, minlen=3):
    idx = np.where(line)[0]; out = []
    if len(idx) == 0: return out
    s = p_ = idx[0]
    for v in idx[1:]:
        if v <= p_ + 2: p_ = v
        else:
            if p_ - s + 1 >= minlen: out.append((int(s), int(p_)))
            s = p_ = v
    if p_ - s + 1 >= minlen: out.append((int(s), int(p_)))
    return out
```

**圆（环拟合）**：在预估中心附近取窗口，取环带内暗像素求重心，半径取均值/90 分位：

```python
def ring_fit(b, cx, cy, r=70):
    ys, xs = np.mgrid[cy-r:cy+r, cx-r:cx+r]
    win = b[cy-r:cy+r, cx-r:cx+r]
    d = np.hypot(xs-cx, ys-cy)
    mask = win & (d < r) & (d > 8)        # 内圈排除中心十字/引线
    px, py = xs[mask], ys[mask]
    mx, my = px.mean(), py.mean()
    rr = np.hypot(px-mx, py-my)
    return mx, my, rr.mean()
```

注意：引线/箭头穿过圆会拉偏重心——缩小窗口或排除箭头所在扇区再拟合。

## 4. 尺寸链反推（关键步骤）

把标注链读成坐标方程，而不是直接信像素：

- 水平链 `3`、`23.7`：边→M3 孔列→中列 → 中列 x = 3+23.7 = 26.7
- 水平链 `4.5`、`22`：边→M2 孔列→中列 → 中列 x = 4.5+22 = 26.5
- 两链给出 26.7 / 26.5 不一致时：按链各自落位（0.2mm 台阶），或取均值并注明
- 竖直 `20`、`12`：外孔对间距 20（±10）、内孔对 12（±6），中心对称

引线归属靠**孔径大小**：M3 圆画得比 M2 大 → 数量对上（如 4 小 + 3 大 = 4-M2 + 3-M3）。

## 5. 坐标系约定

- 主安装面视图：原点 = 前段/机身接缝 × 孔阵中心，y 向上，x 向后（镜头端为负）
- 其他视图（后面板等）用固定 X 偏移并排摆放，局部坐标 + 偏移
- 所有数值写成 mm 小数（保留 3~4 位），生成器内用常量表集中管理
